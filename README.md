# Kasak Portfolio (Android)

An AI & Data Science portfolio Android application built with **Kotlin** and **Jetpack Compose**, adhering to **Material Design 3**.

## Overview
This application showcases the professional journey, research publications, technical achievements, skills, and projects of Kasak — an AI & Data Science specialist, book author, and machine learning researcher.

## Key Features & Architecture
- **Home & Hero Experience:** Profile showcase with adaptive banner, interactive quote, quick-action contact & resume download triggers, and external social connections (LinkedIn, GitHub, Email).
- **Milestones & Achievements:** Deep dive into major milestones including Kasak's published book *"Hello AI: A Friendly Introduction to Machine Learning"* (Eliva Press & Amazon), research paper on *Image to Pencil Recognition using ML & OpenCV* (NCBISF-24), Smart Cities data analytics paper (IJPREMS), and Microsoft Code Veda Hackathon mentorship.
- **Experience & Education:** Timeline tracking roles at Defence Research and Development Organisation (DRDO) developing CampusHire Analytics, Head of Department (Data Science) at Renu Sharma Foundation, academic achievements at Dr. Akhilesh Das Gupta Institute of Professional Studies, and verified NPTEL & IBM certifications with full visual previews.
- **Skills Matrix:** Categorized interactive cards for Programming Languages, Core Concepts, Tools & Platforms, and Libraries & Frameworks with on-demand application tooltips and key metrics counters.
- **Projects Showcase:** Featured project case study (*CampusHire Analytics*), *EmotionsMemoria* AI memory creator with live demo links, *MapMyWork* workforce mapping, OpenCV computer vision tools, and IPL statistics analytics with category filtering.
- **Get In Touch:** Dialog form with automated mailto triggers and validated contact workflows.

## Technology Stack
- **Framework:** Jetpack Compose + Material Design 3
- **Language:** Kotlin 2.1.0 (JVM 21)
- **Architecture:** Clean MVVM with single-source data repository
- **Assets:** High-resolution vector drawables and adaptive launcher icons
